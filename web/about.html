How JoinPDF works

What it does

JoinPDF combines several PDF files into a single PDF. You add files by dragging them onto the page or with the Add files button, put them in the order you want by dragging them, and click Combine & download. Your browser then saves one PDF that contains all pages of all files, in that order.

Your files are never uploaded

Everything happens inside your own browser, on your own device. When you add a file, your browser reads it into its memory. Combining is done by JavaScript running in that same browser tab, using the open-source pdf-lib library. The result is handed straight to your browser's download function.

  • No file, page, file name or file content is ever sent to our server or to anyone else.
  • Nothing is stored: not on the server, and not in your browser either. Close or reload the tab and the files are gone from memory.
  • There are no accounts, no cookies, no analytics, no trackers and no third-party scripts.
  • The only thing remembered is your language choice (English or Dutch), stored in your own browser.

This is not just a promise: the website tells your browser, through its security policy (Content-Security-Policy: connect-src 'none'; form-action 'none'), that this page is not allowed to send data anywhere. Your browser enforces that, so even a bug could not upload your files.

Check it yourself

  • Open your browser's developer tools, go to the Network tab and combine some files: you will see no requests carrying your files.
  • Or load this page, disconnect from the internet, and combine files: it keeps working, because nothing needs the network.
  • The complete source code is public on GitHub (MIT license).

What the server does see

The server only delivers the web page itself (HTML, JavaScript, CSS and the icon). Like any web server it may log technical data about those page requests, such as IP address, time and the page requested, to protect against abuse. It never receives your PDFs.

Limitations

  • Password-protected PDFs can't be combined; they are marked in the list.
  • Pages are copied exactly as they are, without re-rendering, so quality doesn't change.
  • Bookmarks (the document outline) and fillable form fields from the source files are not carried over.
  • Very large files are limited by the memory of your device and browser.

Hoe JoinPDF werkt

Wat het doet

JoinPDF voegt meerdere pdf-bestanden samen tot één pdf. Je voegt bestanden toe door ze naar de pagina te slepen of met de knop Bestanden toevoegen, zet ze in de gewenste volgorde door ze te slepen, en klikt op Samenvoegen & downloaden. Je browser slaat dan één pdf op met alle pagina's van alle bestanden, in die volgorde.

Je bestanden worden nooit geüpload

Alles gebeurt in je eigen browser, op je eigen apparaat. Als je een bestand toevoegt, leest je browser het in zijn geheugen. Het samenvoegen gebeurt door JavaScript in datzelfde browsertabblad, met de open-source bibliotheek pdf-lib. Het resultaat gaat rechtstreeks naar de downloadfunctie van je browser.

  • Er wordt nooit een bestand, pagina, bestandsnaam of inhoud naar onze server of naar iemand anders gestuurd.
  • Er wordt niets opgeslagen: niet op de server en ook niet in je browser. Sluit of herlaad het tabblad en de bestanden zijn uit het geheugen verdwenen.
  • Er zijn geen accounts, geen cookies, geen statistieken, geen trackers en geen scripts van derden.
  • Het enige dat onthouden wordt is je taalkeuze (Engels of Nederlands), opgeslagen in je eigen browser.

Dit is niet alleen een belofte: de website vertelt je browser via het beveiligingsbeleid (Content-Security-Policy: connect-src 'none'; form-action 'none') dat deze pagina nergens gegevens naartoe mag sturen. Je browser dwingt dat af, dus zelfs een fout in de code zou je bestanden niet kunnen uploaden.

Controleer het zelf

  • Open de ontwikkelaarstools van je browser, ga naar het tabblad Netwerk en voeg bestanden samen: je ziet geen verzoeken met je bestanden.
  • Of laad deze pagina, verbreek de internetverbinding en voeg bestanden samen: het blijft werken, omdat er geen netwerk nodig is.
  • De volledige broncode staat openbaar op GitHub (MIT-licentie).

Wat de server wel ziet

De server levert alleen de webpagina zelf (HTML, JavaScript, CSS en het icoon). Zoals elke webserver kan hij technische gegevens over die paginaverzoeken vastleggen, zoals IP-adres, tijdstip en de opgevraagde pagina, om misbruik tegen te gaan. Je pdf's ontvangt hij nooit.

Beperkingen

  • Pdf's met een wachtwoord kunnen niet worden samengevoegd; ze worden in de lijst gemarkeerd.
  • Pagina's worden precies gekopieerd zoals ze zijn, zonder ze opnieuw op te bouwen, dus de kwaliteit verandert niet.
  • Bladwijzers (de inhoudsopgave van het document) en invulbare formuliervelden uit de bronbestanden worden niet overgenomen.
  • Heel grote bestanden worden begrensd door het geheugen van je apparaat en browser.
